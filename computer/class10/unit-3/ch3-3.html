3.3 · Introduction

Introduction to computer graphics

DefinitionComputer graphics is the representation of any image or data that is not in the form of text or sound (cannot be seen). It is done with the help of specialized hardware and software.

  • The word graphics comes from the Greek word "Graphikos", which means to present any object having a specific shape and size through a medium.
  • Computer graphics has revolutionized animation, movies and the video game industries.
  • Some graphics software: MS-Paint, Freehand, Adobe InDesign, CorelDraw, Adobe Photoshop.

3.3 · Raster

Raster graphics

DefinitionRaster graphics are images made up of tiny dots called pixels (picture elements). Each pixel has its own color. Combined, they form a whole picture.

  • Examples: digital photos or images on your phone or computer screen.
  • If you zoom in or enlarge a raster image, it may look blurry or pixelated.
  • File formats: JPEG, PNG and BMP.
3.3 · Vector

Vector graphics

DefinitionVector graphics are images made using mathematical formulas with points, lines and shapes.

  • They can be resized (zoomed in or out) without losing quality, which makes them perfect for logos, icons and illustrations.
  • They stay clear and sharp at any size.
  • File formats: SVG, EPS and AI.

3.3 · Formats

Graphics file formats

TIFF / TIF

Tagged Image File Format. Very large file sizes, uncompressed, detailed. Common in photo software such as Photoshop.

JPEG / JPG

Joint Photographic Experts Group. Compressed, small files. Most digital cameras store photos in JPEG. Common for sharing on websites.

GIF

Graphics Interchange Format. Used for animations. Supports transparency. Simple moving images, logos and memes.

3.3 · Formats

Graphics file formats (continued)

PNG

Portable Network Graphics. Full range of color and better compression. Supports transparency. Ideal for logos, icons and graphics with text.

SVG

Scalable Vector Graphics. Uses lines, shapes and text instead of pixels. Stays clear even when zoomed in.

PDF

Portable Document Format. Keeps text, images and layout the same on any device. Used for e-books, reports and forms. Harder to edit.
