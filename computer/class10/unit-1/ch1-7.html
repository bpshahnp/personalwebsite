1.7 · Network Architecture

Network architecture

DefinitionNetwork architecture is the network design that describes how the computers on the network interact and communicate with each other. It is the combined form of network topologies and mode of data transmission between the computers.

Network architecture can be classified into two types:

Client-server

Peer-to-peer

1.7 · Client-Server

Client-server architecture

DefinitionThe network mode with at least one server and other clients is called the client-server network. It is the more common type of network architecture.

  • It uses a central server and specialized network software. The server is dedicated and only used to store files and run server tasks.
  • Clients request services and the server provides them. The server is a powerful computer with greater processing speed and storage than a client.
  • Servers may be file, printer, message, application or web servers. This gives easier network administration and secure access to data.
1.7 · Client-Server

Client-server: advantages and limitations

Advantages

Covers a larger geographical area. The cabling scheme can range from the simplest to the most complicated. Reduces network traffic. Centralizes network management and security on the server.

Limitations

Too many client requests can overload and break down the server. If the server fails, the whole network goes down. Expensive to install and manage. Needs professional manpower to maintain the servers.

1.7 · Peer-to-Peer

Peer-to-peer architecture

DefinitionPeer-to-peer is a type of network architecture where several computers are connected to each other. All computers function both as a client and a server, with equal responsibilities. There is no central data storage.

  • The network consists of shared folders located on computers in the network. Other users can access them.
  • Any printer connected to any computer can be shared with other network users.
1.7 · Peer-to-Peer

Peer-to-peer: advantages and limitations

Advantages

All resources and contents are shared by all peers. More reliable, since failure of one peer does not affect the others. No need for a full-time system administrator. Low cost to build and maintain.

Limitations

The system is decentralized, so it is difficult to administer. Security is very low. Data recovery or backup is difficult, since each computer needs its own backup system.

1.7 · Protocol

Communication protocol

DefinitionA protocol is a set of rules that governs data transmission. It defines what is communicated, how it is communicated and when it is communicated.

  • Rules are needed for sending and receiving information between computers in the network.
  • The Network Control Protocol (NCP) was the first protocol. Later, TCP/IP was developed, and it is still in use today.
1.7 · Protocols

Common protocols

TCP/IP

Transmission Control Protocol/Internet Protocol. Used in Internet devices and in private networks.

FTP

File Transfer Protocol. Transfers files over connected computers.

HTTP

Hypertext Transfer Protocol. Used by web servers and clients to communicate.

IMAP

Internet Message Access Protocol. Accesses e-mail on a remote server from a local client.

1.7 · Protocols

Common protocols (continued)

POP

Post Office Protocol. Receives mail from an e-mail server.

SMTP

Simple Mail Transfer Protocol. Sends e-mail.

TFTP

Trivial File Transfer Protocol. A simple protocol to read and write files from a remote server.

PPP

Point to Point Protocol. Used in broadband communications with heavy loads and high speed.

1.7 · Protocols

More protocols and DHCP

NNTP

Network News Transfer Protocol. Transports news articles between news servers and lets clients read and post them.

IPX/SPX

Internetwork Packet Exchange/Sequenced Packet Exchange. Used in Novell Network Operating System (NNOS).

NetBEUI

NetBIOS Extended User Interface. Used in small local area networks.

DHCP

Dynamic Host Configuration Protocol. Automatically gives devices on a network an IP address.

1.7 · Summary

Key terms to remember

Client-server

Central server. Secure, costly.

Peer-to-peer

Equal computers. Cheap, less secure.

Protocol

A set of rules for data transmission.

TCP/IP

Main protocol of the Internet.

SMTP and POP

SMTP sends mail. POP receives it.
