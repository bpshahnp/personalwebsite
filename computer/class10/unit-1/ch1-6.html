1.6 · Computer Network

Computer network

DefinitionA computer network is the interconnection of several computers so that they can communicate, share resources and transfer data and information.

  • Many computers of the same location or different locations are connected by wired or wireless media. We can share resources such as printers and scanners.
  • A network can be two computers on a desk, or many LANs connected to form a WAN across a continent.
  • The largest network is the Internet, also called the network of networks.
1.6 · Network Services

Services provided by a network

Network services are the things a network can do. The major services are:

Message

Lets networked computers exchange messages reliably, even on different machines or locations.

File

Lets users access, store and share files on network servers.

Print

Lets many users send print jobs to shared printers, in the correct order.

Application

Provides software applications over the network without installing them locally.

1.6 · Network Services

More network services

Database

Lets multiple users store, retrieve and manage data in a central database, with consistency, security and concurrent access.

Network management

Monitors and controls network resources. It detects faults, manages traffic and optimizes operations.

Security

Provides authentication, authorization and protection of data. Only authorized users can access resources.

1.6 · PAN

Personal Area Network (PAN)

DefinitionA PAN is the smallest type of network, used to connect devices within a short range (usually up to 10 meters). It is mainly used by one person for personal tasks.

Examples

Connecting a smartphone to a Bluetooth speaker. Using Wi-Fi to transfer files between laptop and mobile. Smartwatches connected to phones.

Types

Wired PAN: uses USB or cables (a mouse to a computer). Wireless PAN: uses Bluetooth, infrared or Wi-Fi (a mobile hotspot).

1.6 · PAN

Features of PAN

  • Short range, up to 10 meters. Intended for personal use.
  • Bluetooth, infrared and USB cables can be used with a wireless or wired device.
  • Requires less power, particularly wireless PANs.
  • Easy to set up and affordable to operate and maintain.
  • Supports a limited number of linked devices.
1.6 · LAN

Local Area Network (LAN)

DefinitionA LAN is a computer network limited to a small area such as a room, a building or a school. It connects a limited number of computers and other devices.

  • Computers and hardware such as printers are connected by copper cable or fibre cable.
  • Signals must be boosted by repeaters along the way, because LANs are limited by distance.
  • By creating a LAN, we can share hardware and software resources between computers.
1.6 · LAN

Features of LAN

  • Covers a limited geographical area of about a few kilometers.
  • High speed data transfer, about 10 to 100 Mbps.
  • Normally owned by a single organization.
  • Provides full time connectivity to local services.
  • Uses guided transmission media and is unaffected by environmental factors.
1.6 · MAN

Metropolitan Area Network (MAN)

DefinitionA MAN is a medium sized network that covers a larger area than a LAN but smaller than a WAN, such as a university, a city, a valley or a district.

  • Several LANs in different locations are connected through telephone line, optical fiber cable or wireless media.
  • Typically owned and operated by a single entity such as a government body or a large corporation.
  • Suited to medium sized organizations having different branches within a city or region.
1.6 · MAN

Features of MAN

  • Covers a larger area than a LAN and connects a larger number of computers.
  • Uses cable or wireless media to connect computers.
  • Connects multiple LANs in different locations using Ethernet technology.
  • Owned by a single or multiple organizations.
  • Offers network services with bandwidths from 128 kbps to 1 Gbps.
1.6 · WAN

Wide Area Network (WAN)

DefinitionA WAN covers a large geographical area such as cities, countries or continents. The Internet is the most common example of a WAN.

  • A WAN is created by connecting multiple LANs and MANs through high-speed links such as fiber-optic cables, satellite systems or microwave transmission.
  • Widely used by banks, multinational companies, government offices and international organizations.
  • Supports email, online banking, video conferencing, cloud computing and centralized data storage.
1.6 · WAN

Features of WAN

  • Not restricted to a geographical location. It covers the whole world.
  • Uses satellite links or microwave systems to connect several LANs and MANs.
  • Owned by multiple organizations.
  • High speed technology, but very expensive to set up and complex to maintain.
  • Data transmission in a WAN is slower than in a LAN.
1.6 · Terms

Clients and server

Client

A network computer, except the server, on which users run applications. Less powerful, with lower processing speed and storage. Depends on the server and requests it for information.

Server

A service provider in the network. Powerful, with high processing speed and large storage. Provides services in response to client requests. Runs a network operating system (NOS) and has central authority.

1.6 · Terms

Node and workstation

Node

Any active electronic device connected to a network that can receive, generate, process or forward information. A computer, modem, hub, bridge or switch is a node.

Workstation

A computer built to run heavy and professional software. It stores more data, runs more applications, and handles many tasks at once. It often runs Unix or Linux.

1.6 · Advantages and Limitations

Advantages of computer network

  • Computers can easily share information with each other.
  • Efficient management of resources. Users share printers and hard disks.
  • Software can be shared, saving money on multiple copies.
  • Data stays reliable and up to date. Updating a file on one system makes it available on other systems.
  • An easy way to back up important data. Record locking lets many users access the same file without corrupting it.
1.6 · Advantages and Limitations

Limitations of computer network

Virus spread

Computer viruses spread mostly through networks.

Data misuse

Fear of misappropriation of data.

High cost

The initial setup cost is very high.

Cyber crime

Cyber crime may occur.
