1.5 · Network Topologies

Network topologies

DefinitionNetwork topology refers to the arrangement and connection patterns of computers in the network. It is the physical layout of the terminals, links and computers in the network.

It can be defined as the cabling structure or geometrical arrangement of computers in a Local Area Network. It is also known as Network Topology or LAN Topology. Some topologies used in LAN are:

Bus or linear

Star

Ring

Hybrid

1.5 · Bus Topology

Bus or linear topology

DefinitionIn bus topology, all computers, servers and other devices are connected to a single central cable called the bus.

  • Each device communicates with others through this bus. Terminators are attached at both ends of the cable to prevent data from leaving the network.
  • If the bus has only two endpoints, the topology is called a linear bus topology.
  • It depends heavily on the central cable. If the bus fails, the entire network stops functioning. It also has a higher chance of data collisions.
1.5 · Bus Topology

Bus topology: advantages and limitations

Advantages

It is easy to set up and extend. Comparatively cheaper. The cable length required is the least compared to other networks. Linear bus is mostly used in small networks.

Limitations

If the main cable (bus) has any problem, the whole network breaks down. Maximum chance of collision of data. Difficult to detect and troubleshoot a fault at an individual station.

1.5 · Star Topology

Star topology

DefinitionIn star topology, all devices are connected to a central device. The central device can be a hub, switch or router.

  • Devices do not share a single cable. Each device has a direct connection to the central device.
  • All data passes through the central device before reaching its destination. The central device manages the network and controls data flow. It can also act as a repeater to strengthen signals.
  • It is one of the most widely used topologies in LANs. It uses different cables, such as UTP, coaxial or optical fiber.
1.5 · Star Topology

Star topology: advantages and limitations

Advantages

Much better performance than bus topology. New nodes can be added easily without affecting the rest of the network. Centralized management helps in monitoring the network. Failure of one node or link does not affect the rest of the network.

Limitations

If the central device (hub or switch) fails, the entire network breaks down. The central device increases the overall cost. Performance and the number of nodes depend on the capacity of the central device. More cable is required, which can make installation difficult and costly.

1.5 · Ring Topology

Ring topology

DefinitionRing topology is a network topology where all devices are connected in a closed circular loop. Each device is connected to two neighboring devices.

  • There is no central device to control the network. All devices have equal access to send and receive data.
  • Data travels in one direction only, clockwise or anti-clockwise. This ensures organized communication and prevents data collisions.
1.5 · Ring Topology

Token passing in a ring

Ring networks use a token-passing method to send data. A token is a special signal or empty packet.

1. Capture

A device that wants to send data captures the token.

2. Send

It attaches its data and the destination address, and passes it along the ring.

3. Check

Each device checks if the data is for it.

4. Receive or pass

If yes, it receives the data and releases a new token. If not, it passes the token to the next device.

1.5 · Ring Topology

Ring topology: advantages and limitations

Advantages

Data transmits in one direction only, which reduces the chances of data collision. No need for a network server to control the connectivity between workstations. Additional components do not affect the performance of the network. Each computer has equal access to resources.

Limitations

Each packet of data must pass through all the computers between source and destination, so it is slower than star topology. If one workstation or port goes down, the entire network gets affected. The network is highly dependent on the wire connecting the different components.

1.5 · Hybrid Topology

Hybrid topology

DefinitionA hybrid topology is a network structure that mixes two or more different types of topologies (like star, bus and ring) in one network.

  • It combines the strengths of each topology and helps build a more reliable and efficient network.
  • Example: a university may use a star topology in its computer lab (easy to manage) and a bus topology to connect the different buildings or departments (cost-saving), all combined into a single hybrid network.
1.5 · Hybrid Topology

Hybrid topology: advantages and limitations

Advantages

It can be designed based on requirements. If one part fails, it does not crash the whole network. New devices can be added easily. It combines the best parts of each topology.

Limitations

It needs more devices, cables and planning. It is harder to set up and maintain. It needs skilled technicians because configuration can be difficult. Hybrid topologies are complex to design and can be expensive.

1.5 · Summary

Key terms to remember

Topology

The arrangement of computers in a network.

Bus

Single central cable with terminators.

Star

Central hub or switch.

Ring

Closed loop, one direction, token passing.

Hybrid

Mix of two or more topologies.
