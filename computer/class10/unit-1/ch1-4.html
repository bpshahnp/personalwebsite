1.4 · Networking Devices

What makes a computer network

Different components are used to create a computer network. The main components are hardware components and software.

Hardware

Computers. Transmission devices such as NIC, hub, switch, bridge, gateway, repeater and router. Channels such as wires, microwaves, radio waves and satellite.

Software

Network Operating System (NOS) and communication protocol.

1.4 · Repeater

Repeater

DefinitionA repeater is a network device that extends the length of a network by amplifying weak data signals.

  • It receives weakened signals from the network medium (such as cables or wireless transmission), regenerates them and retransmits them over longer distances, without losing quality.
  • Repeaters do not manage network traffic or decide the path that data should take. They simply boost the signals.
  • Commonly used in large offices, schools and networks where the distance between devices is greater than the normal range of the network medium.
1.4 · Hub

Hub

DefinitionA hub is a network connecting device used in a Local Area Network (LAN), especially in star topology. It is a simple, inexpensive device that joins multiple computers together.

  • The most commonly used type is the Ethernet hub. It is also called a multiport repeater.
  • A hub cannot identify the source and intended destination of the information it receives, so it sends the information to all of the computers connected to it.
  • It can send or receive information but not both at the same time, so it works slower than switches or routers. It is a half duplex device.
1.4 · Switch

Switch

DefinitionA switch is a network connecting device that joins multiple computers together within a local area network (LAN) in star topology.

  • Switches work almost like hubs, but they can identify the intended destination of the information, so they send it only to the computers that should receive it.
  • A switch inspects data packets, determines the source and destination of each packet and forwards them appropriately. It can send and receive information at the same time, so it works faster than a hub. It is a full duplex device.
  • It figures out which device is connected to which port (addresses of connected devices) and forwards data only to the intended recipient, rather than broadcasting it to every port.
1.4 · Switch and Hub

Difference between switch and hub

SwitchHub
1A more sophisticated network device and more expensive than a hub.A very primitive device and comparatively much cheaper.
2An "intelligent" device. It transmits the data packets only to the destination computers to which they are intended.A "dumb" device. It broadcasts the data packets to each and every networked computer, not just the target computer.
3Optimum utilization of network bandwidth. Bandwidth wastage is minimal.Unnecessary wastage of network bandwidth, which results in slow operation and data transfer speeds.
4Full-duplex device: transmission and reception can take place simultaneously.Half-duplex device: transmission and reception cannot take place simultaneously.
1.4 · Router

Router

DefinitionA router is a network connecting device that joins multiple wired or wireless networks together. It connects two different networks having similar protocol.

  • A complex network needs a device which not only knows the address of each segment, but can also determine the best path for sending data and filter broadcast traffic to the local segment. Such a device is called a router.
  • Routers are usually used in a complex network situation because they provide better traffic management than other devices.
  • A router passes information only if the network address is known. This ability to control the data passing through reduces the amount of traffic between networks.
1.4 · Router and Switch

Difference between router and switch

RouterSwitch
1Used to connect two or more different networks.Connects different computers within the same network.
2Much more sophisticated and intelligent than switches.Less sophisticated and less intelligent than routers.
3Works on the principle of IP (Internet Protocol) addresses.Works on the basis of MAC (Media Access Control) addresses.
4Has its own inbuilt operating system and needs to be configured before use.Most switches do not need prior configuration. They are usually "ready-to-use".
1.4 · Bridge

Bridge

DefinitionA bridge connects different network segments, or different networks having similar protocols.

  • Bridges reduce the amount of traffic on a LAN by dividing it into two segments.
  • They operate at the data link layer (Layer 2) of the OSI model. A bridge inspects the incoming traffic and decides whether to forward or discard it.
  • Generally, it is used to connect similar LANs having the same communication protocols.
1.4 · Summary

Key terms to remember

Repeater

Amplifies weak signals to extend a network.

Hub

Dumb, half duplex. Sends data to all computers.

Switch

Intelligent, full duplex. Sends data only to the intended computer.

Router

Joins different networks. Uses IP addresses.

Bridge

Connects network segments with similar protocols.
