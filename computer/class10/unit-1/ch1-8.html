1.8 · IP Address

IP address

DefinitionAn IP address (Internet Protocol address) is a unique number given to every device connected to a computer network, like the Internet, to identify and locate it.

It is like the home address of your device on the Internet. Without it, data would not know where to go. It is needed:

Identify

To identify a device on a network.

Send and receive

To send and receive data from the correct device.

1.8 · IPv4

IPv4 address

DefinitionIPv4 (Internet Protocol version 4) is the fourth version of the Internet Protocol and the most widely used version for addressing and routing devices on the Internet.

  • A 32-bit number. It allows about 4.3 billion unique addresses.
  • Divided into four parts called octets, separated by dots. Each octet has a value from 0 to 255.
  • Example: 192.168.1.1. Each octet is 8 bits.
1.8 · IPv4

Parts of an IPv4 address

Network portion

Identifies the specific network.

Host portion

Identifies a device within that network.

Because of the rapid growth of devices, IPv4 addresses are running out. Two techniques help:

Private IP ranges

10.x.x.x, 172.16.x.x to 172.31.x.x and 192.168.x.x are reserved for private networks and are not routable on the public Internet.

NAT

Network Address Translation lets many devices on a private network share one public IPv4 address. Routers replace private addresses with the public one.

1.8 · IPv4 Types

Public and private IPv4 address

Public IP

Globally unique and can be used to communicate with devices anywhere on the Internet. Assigned by ISPs. Example: 8.8.8.8 (Google DNS server).

Private IP

Used inside a local network (LAN) and cannot be routed on the public Internet. Different private networks can reuse the same ranges. Translated into one public IP using NAT.

1.8 · IPv4

IPv4: advantages and limitations

Advantages

Easy to understand and use. Widely used and works on almost all devices. Simple address format. Efficient and reliable for small networks. Can use NAT to let many devices share one public IP.

Limitations

Only a limited number of addresses, and most are already used. No built-in security. Needs NAT to connect to the Internet, which can be complicated. Cannot easily support the growing number of Internet devices.

1.8 · IPv6

IPv6 address

DefinitionIPv6 (Internet Protocol version 6) is the sixth version of the Internet Protocol, developed to overcome the shortage of IPv4 addresses.

  • It uses 128-bit addresses, about 3.4 × 10³⁸ unique addresses (340 undecillion).
  • Written in hexadecimal notation, in eight groups separated by colons (:). Each group has four hexadecimal characters (0–9 and A–F).
1.8 · IPv6

IPv6 example and short form

Example IPv6 address

2001:0db8:85a3:0000:0000:8a2e:0370:7334

Remove leading zeros

2001:0db8:0000:0000:0000:ff00:0042:8329
becomes
2001:db8:0:0:0:ff00:42:8329

Replace consecutive zeros with ::

2001:db8:0:0:0:ff00:42:8329
becomes
2001:db8::ff00:42:8329
This can be done only once in an address.

1.8 · IPv6

Parts of an IPv6 address

Network prefix

Similar to the network portion in IPv4. It identifies the specific network.

Interface identifier

Similar to the host portion. It identifies a device on that network.

  • IPv6 supports auto-configuration, so devices can generate their own addresses without manual setup or DHCP.
1.8 · IPv6 Types

Types of IPv6 address

Unicast

Sends data to one specific device (one-to-one). Global unicast addresses start with 2000::/3.

Multicast

Sends data to a group of devices at the same time. Starts with ff00::/8.

Anycast

Shared by many devices. Data goes to the nearest one, for faster and reliable services like DNS.

1.8 · IPv6 Types

More IPv6 address types

Link-local

Used only inside the same local network. Starts with fe80::/10. Cannot be used on the Internet.

Global unicast

A public address reachable over the Internet. Unique worldwide. Starts with 2000::/3.

Unique local (ULA)

Used inside private networks, like private IPv4 addresses. Starts with fd00::/8.

  • IPv6 does not use broadcast. It uses multicast to send data to multiple devices efficiently.
1.8 · IPv6

IPv6: advantages and limitations

Advantages

Huge number of addresses. Simpler format for routers, so the Internet works faster. Built-in security. Devices create their own IP automatically. No need for NAT. Works better with mobile devices. Sends data to many devices more efficiently.

Limitations

Addresses are long and hexadecimal, which can be confusing. Changing from IPv4 to IPv6 can be hard and expensive. Older devices may not work. Upgrading takes time and money. Not everyone uses IPv6 yet.

1.8 · Summary

Key terms to remember

IP address

Unique number identifying a device.

IPv4

32 bits, four octets, 0 to 255.

IPv6

128 bits, hexadecimal, colons.

NAT

Shares one public IP among private devices.

Classes

A, B, C for hosts. D multicast. E experimental.
