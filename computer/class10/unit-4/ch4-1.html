Introduction to Python

Textbook DefinitionPython is a high-level, general-purpose programming language known for its readability and simplicity.

  • Created by Guido van Rossum and first released in 1991.
  • Supports multiple programming paradigms: procedural, object-oriented, and functional programming.

  • Widely used across Data Science, Artificial Intelligence, Web Development, Software Engineering, and Automation.

4.1 · Lesson 1: Basics & Variables

Python Variables

DefinitionA variable is the name of a memory location used to store values.

No Declaration Command

Python has no command for declaring variables (unlike C, C++, or Java). A variable is created the moment you first assign a value to it.

Dynamic Typing

Python automatically determines the data type according to the assigned value. No need to specify int, float, or string.

Dynamic Re-assignment

Once created, you can alter its stored value and even its data type simply by assigning a new value.

4.1 · Lesson 1: Basics & Variables

Rules for Python Variables

Identifiers must adhere to strict lexical rules recognized by the Python interpreter:

  • Variable names must start with a letter (a–z, A–Z) or an underscore (_).
  • Variable names cannot start with a number (e.g. 2rank is illegal; rank2 is valid).
  • Can only contain alphanumeric characters and underscores (a-z, A-Z, 0-9, and _). No spaces or special symbols like $, @, %.
  • Variables are case-sensitive: name, Name, and NAME are three distinct variables.
  • Reserved words (keywords) cannot be used as variable names (e.g., if, for, while, class, def).

Input / Output (I/O) in Python

The input() Function

FunctionTakes user input from the keyboard. The program pauses and waits until the user types something and presses Enter.

  • Always returns a string (text) by default!
  • To receive numbers, use type casting: 
    age = int(input("Enter age: "))
rate = float(input("Enter interest rate: "))

The print() Function

FunctionOutputs text, numbers, variable values, or calculation results to the screen or console.

# Syntax 1: print variable
name = "Aayush"
print(name)

# Syntax 2: print literal values
print(5)
print("hello")
print("apple", "banana", "orange")
4.1 · Lesson 2: I/O & Formatting

The end Parameter in print()

By default, print() automatically appends a newline character (\n), moving the cursor down.

Using end="..." overrides this default behavior:

  • end=" ": keeps output on the same line separated by a space.
  • end="": joins printed items directly together.
  • end=",": adds a comma between consecutive outputs.
  • end=" - ": adds dashes between outputs.
for x in range(1, 10, 2):
    print(x, end=" ")

4.1 · Lesson 3: Operators

Operators and Operands

DefinitionOperators are signs or symbols that instruct the interpreter to perform specific mathematical, relational, or logical operations.

  • An operand is a value, variable, or constant operated on by an operator (in 5 + 3, 5 and 3 are operands; + is the operator).
  • Four primary categories of operators in Grade 10 Python:

Arithmetic

Perform math calculations: +, -, *, /, //, %, **

Relational

Compare two operands and return True or False: ==, !=, <, >, <=, >=

Assignment

Assign and update values in memory: =, +=, -=, *=, /=, %=

Logical

Evaluate multiple conditions: and, or, not

4.1 · Lesson 3: Operators

Assignment & Compound Operators

Simple vs Compound

Simple: x = 10 assigns 10 to variable x.

Compound combines arithmetic with assignment:

x = 10
x += 5   # x = x + 5  -> 15
x -= 3   # x = x - 3  -> 12
x *= 2   # x = x * 2  -> 24
x /= 4   # x = x / 4  -> 6.0
x %= 2   # x = x % 2  -> 0.0
x **= 3  # x = x ** 3 -> 0.0

Increment & Decrement

Python has no x++ or x-- operators. Use compound operators:

# Increment by 1
x += 1    # Equivalent to x = x + 1

# Decrement by 1
x -= 1    # Equivalent to x = x - 1
4.1 · Lesson 3: Operators

Logical Operators

Used to combine or invert Boolean expressions (True / False):

and (Logical AND)

Returns True only if both operands are True. Otherwise returns False.

5 > 2 and 10 > 3  # True
5 > 2 and 10 < 3  # False

or (Logical OR)

Returns True if at least one operand is True. Returns False only if both are False.

5 < 2 or 10 > 3   # True
5 < 2 or 10 < 3   # False

not (Logical NOT)

Inverts the Boolean value: returns False if condition is True, and True if condition is False.

not (5 > 2)       # False
not (5 < 2)       # True
4.1 · Lesson 4: Conditionals

Conditional Statements & Indentation

ConceptConditional statements make decisions in programs, executing specific blocks of code depending on whether a condition is True or False.

  • Python uses indentation (whitespace) to define code blocks instead of curly braces { }.
  • Every conditional header must conclude with a colon (:).
  • Statements aligned at the same indentation level belong to the same block.

if statement

Executes a single block only when condition is True.

if-else statement

Executes one block if True, alternate block if False.

if-elif-else

Tests multiple sequential conditions in a ladder.

4.1 · Lesson 4: Conditionals

if and if-else Statements

if statement

num = 5
if num > 0:
    print("The number is positive.")

If condition is True, indented lines execute. If False, they are bypassed.

if-else statement

num = int(input("Enter number: "))
if num % 2 == 0:
    print(num, "is even.")
else:
    print(num, "is odd.")

Provides two distinct execution paths depending on condition test.

4.1 · Lesson 4: Conditionals

if-elif-else Ladder

Used to evaluate multiple conditions sequentially:

num = float(input("Enter a number: "))
if num > 0:
    print("Positive number")
elif num == 0:
    print("Zero")
else:
    print("Negative number")

4.1 · Lesson 5: Looping

Iteration (Looping) in Python

DefinitionIteration is the process where statements or code blocks are executed repeatedly until a specified condition is satisfied.

for Loop

Iterates over a sequence (list, tuple, string, or range). Used primarily when the number of iterations is known in advance.

while Loop

Repeatedly executes as long as a test condition remains True. Used when the number of iterations is not known in advance.

4.1 · Lesson 5: Looping

The range() Function

Generates an arithmetic progression of integers for loops:

range(stop)

Generates numbers from 0 up to stop - 1.

range(5) → 0, 1, 2, 3, 4

range(start, stop)

Generates numbers from start up to stop - 1.

range(1, 5) → 1, 2, 3, 4

range(start, stop, step)

Increments each value by step.

range(1, 10, 2) → 1, 3, 5, 7, 9

4.1 · Lesson 5: Looping

while Loop

Repeats statements while a condition evaluates to True:

i = 1          # 1. Initialization
while i < 6:   # 2. Condition Test
    print(i)
    i += 1     # 3. Increment / Update

CautionIf the loop control variable is never updated, the condition remains True perpetually, creating an infinite loop.

4.1 · Lesson 6: Lists

Lists in Python

DefinitionA list is a built-in data structure that holds an ordered, mutable collection of items enclosed in square brackets [ ].

Ordered

Items have a defined sequence that does not change unless modified.

Mutable

Elements can be modified, appended, inserted, or removed in place.

Heterogeneous

Can contain mixed data types: [10, "Python", 3.14, True]

Duplicates Allowed

Duplicate values can exist at separate indices: [5, 10, 5]

4.1 · Lesson 6: Lists

List Indexing

Python lists use zero-based indexing to access elements:

name = ["Sunrise", "Publication", "Computer Science"]

print(name[1])  # Publication
print(name[2])  # Computer Science

# Negative indexing:

4.1 · Lesson 7: Dictionaries

Dictionaries in Python

DefinitionDictionaries store data in key: value pairs enclosed in curly braces { }. They are ordered (since Python 3.7), changeable, and do not allow duplicate keys.

data = {
    "Nepal": "Kathmandu",
    "India": "New Delhi",
    "Bhutan": "Thimpu"
}
# Accessing via key:
print(data["Nepal"])   # Kathmandu
  • Keys must be unique: Duplicate keys overwrite existing values.
  • Keys must be immutable: Commonly strings or integers.
  • Values can be of any data type and can duplicate.

4.1 · Lesson 9: Programs & Dry Run

Core Textbook Algorithms

1. Factorial of a Number

num = int(input("Enter number: "))
fact = 1
for i in range(1, num + 1):
    fact *= i
print(f"Factorial of {num} is {fact}")

2. Reverse a Number

num = int(input("Enter number: "))
rev = 0
while num > 0:
    digit = num % 10
    rev = rev * 10 + digit
    num //= 10
print("Reversed:", rev)

3. Counting Vowels

word = input("Enter word: ").upper()
c = 0
for ch in word:
    if ch in "AEIOU":
        c += 1
print("Vowels:", c)
