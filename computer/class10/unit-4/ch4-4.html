4.4 · Lesson 1: Intro to Turtle

Introduction to Turtle Graphics

Textbook DefinitionTurtle is an inbuilt Python module used to draw graphical images and animations by controlling a virtual "turtle" on the screen. The turtle acts as a cursor or pen that moves across the screen based on commands.

Inbuilt in Standard Library

Included with Python automatically. No installation required. Just write import turtle.

Cartesian Canvas

The screen center is coordinate (0, 0). X-axis runs horizontally, Y-axis runs vertically.

Educational Power

Used to introduce computational thinking, visual geometry, game creation, and algorithm visualization.

4.4 · Lesson 3: Turtle Motion

Forward and Backward Motion

forward(distance) or fd()

Moves the turtle forward in its current facing direction by distance pixels:

import turtle
d = 200
turtle.forward(d)
turtle.done()

backward(distance) or bk()

Moves the turtle backward by distance pixels without changing its orientation:

import turtle
d = 200
turtle.backward(d)
turtle.done()
4.4 · Lesson 4: Direction & Turns

Turning: Right, Left & Home

right(angle) or rt()

Turns the turtle clockwise by the given angle in degrees without altering its position.

turtle.right(90)

left(angle) or lt()

Turns the turtle counter-clockwise by the given angle in degrees.

turtle.left(90)

home()

Returns the turtle back to coordinates (0, 0) and points it East (0°).

turtle.home()
4.4 · Lesson 5: Pen Controls

Pen Controls & Movement Speed

penup() & pendown()

  • penup() / pu() / up(): Lifts pen off canvas. Movement leaves no trace.
  • pendown() / pd() / down(): Lowers pen onto canvas to draw while moving (default).
turtle.forward(100)
turtle.penup()     # no drawing
turtle.forward(100)
turtle.pendown()   # resume drawing
turtle.forward(100)

pensize() & speed()

  • pensize(width): Sets line width in pixels.
  • speed(value): Value from 0 to 10.
    • 1: Slowest
    • 10: Fast
    • 0: Instant (no animation delay)
4.4 · Lesson 6: Colors

Colors & Color Modes

Pen & Fill Colors

# Set pen stroke color
turtle.pencolor("blue")

# Set shape fill color
turtle.fillcolor("green")

# Set both at once: color(pen, fill)
turtle.color("red", "yellow")

Color Formats

  • Named Colors: "red", "blue", "green", "black".
  • RGB Tuple: 3 integers (0–255) representing Red, Green, and Blue: 
    turtle.colormode(255)
turtle.color((255, 128, 0))

4.4 · Lesson 8: Filling

Filling Polygons with Color

Filling PatternTo paint the interior of any closed geometric shape, wrap the perimeter drawing instructions between begin_fill() and end_fill().

import turtle

sq = turtle.Turtle()
sq.fillcolor("yellow")
sq.pencolor("blue")
sq.pensize(3)

sq.begin_fill()
for i in range(4):
    sq.forward(100)
    sq.right(90)
sq.end_fill()

turtle.done()

How it Works

  • begin_fill() remembers the start vertex of the polygon.
  • The turtle traces the boundary.
  • end_fill() connects start and end vertices and floods the interior with fillcolor.

4.4 · Lesson 10: Review

clear() vs reset() & Summary

turtle.clear()

Clears drawings from the screen. Does not move the turtle; heading and position remain unchanged.

turtle.reset()

Clears all drawings AND resets the turtle to (0, 0) facing East with default settings.

Key Exam Takeaway

For any regular n-sided polygon, turn angle = 360 / n degrees (e.g. Square: 90°, Triangle: 120°, Hexagon: 60°).
