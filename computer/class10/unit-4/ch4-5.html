Lesson 4.5.1 · Foundations

Bugs & Errors in Programming

In software development, there is very little chance that a program runs 100% perfectly the first time. Detecting and fixing errors is a universal software skill.

What is a Bug / Error?

An error or bug is a flaw or mistake in a program that prevents it from executing or causes it to generate erroneous results.

Debugging is the systematic process of finding, tracing, and resolving bugs in program code.

What is an Exception?

An exception is an anomalous condition or event that occurs during program execution that interrupts the normal flow of instructions.

Both errors and exceptions can happen, but Python provides special structures to catch and resolve exceptions safely.

Lesson 4.5.1 · Error Classification

The Three Major Types of Errors

1. Syntax Errors

Violations of Python's grammatical rules and format. Caught before execution during parsing.

E.g., missing :, unclosed quotes.

2. Semantic / Logical Errors

Flaws in reasoning, algorithm, or mathematical formula. Code runs but outputs wrong data.

E.g., length + breadth instead of length * breadth.

3. Runtime Errors

Impossible operations attempted while code is executing. Causes program crash unless handled.

E.g., 10 / 0, accessing missing index.

Lesson 4.5.2 · Syntax Errors

Understanding Syntax Errors

The set of rules that a programmer must follow when writing Python code is called Python syntax.

Why Syntax Errors Happen

  • Missing punctuation (e.g. missing colon : at the end of if, for, def)
  • Incorrect indentation (mixing tabs/spaces or unaligned blocks)
  • Misspelling reserved keywords (e.g. whlie instead of while)
  • Unmatched parentheses (), brackets [], or unclosed quotation marks ""

When Are They Caught?

Syntax errors are detected before the program runs, as the interpreter checks the code structure first during the parsing phase.

# SyntaxError Example:
if x > 10
    print("Greater")
# ^ SyntaxError: expected ':'
Lesson 4.5.2 · Diagnostics

Reading Python's SyntaxError Traceback

The Caret (^) Marker

When Python encounters a syntax error, it prints the filename, line number, and points a caret ^ directly at the first token that failed grammar validation.

  File "calc.py", line 4
    if num > 0
              ^
SyntaxError: expected ':'

Exam Rule: Official CDC Question (g)

Question: Which type of error occurs in the program if programmers violate the rules and format of the program?

Answer: Syntax Error

Remember: If it breaks Python's grammatical formatting rules, it is always a Syntax Error!

Lesson 4.5.3 · Logical Errors

Semantic (Logical) Errors

A semantic error occurs when code runs without any syntax errors or runtime crashes, but does not produce the intended result.

Root Causes of Logical Errors

  • Flawed Algorithm: Misunderstanding the logic required to solve the problem.
  • Wrong Operator: Typing + instead of *, or / instead of //.
  • Incorrect Precedence: Missing parentheses in complex math expressions (e.g. a + b / 2 instead of (a + b) / 2).
  • Off-By-One Loops: range(1, 10) only loops up to 9, missing 10!

Why They Are Dangerous

Unlike syntax and runtime errors, Python produces NO warning or error message for logical errors!

The computer does exactly what you told it to do, not what you intended to do.

Lesson 4.5.3 · Debugging Tactics

How to Identify & Fix Logical Errors

1. Trace / Dry Run

Manually step through the code on paper with small sample inputs, tracking variable values line by line.

2. Print Debugging

Insert temporary print() statements before and after calculations to verify intermediate states.

3. Known Test Cases

Test your program using inputs with known, pre-calculated outputs (e.g. radius=7 gives area ≈ 153.94).

Lesson 4.5.4 · Runtime Failures

Run-time Errors & Built-in Exceptions

A runtime error occurs during program execution when the computer is asked to perform an operation that is impossible or illegal.

Common Runtime Exceptions

  • ZeroDivisionError: Attempting to divide a number by zero (e.g. 25 / 0).
  • IndexError: Accessing an index outside sequence bounds (e.g. nums[5] when length is 3).
  • ValueError: Wrong value type passed to a function (e.g. int("hello")).
  • TypeError: Incompatible type operation (e.g. "age: " + 16).
  • NameError: Using an undeclared variable name.

The Impact of Unhandled Exceptions

When an unhandled exception occurs, Python abruptly halts program execution and prints a traceback.

In real-world apps, this means sudden application crash, lost work, and poor user experience!

Lesson 4.5.5 · Exception Handling

The try...except Architecture

Exception handling is used to handle unexpected runtime errors gracefully and prevent the program from crashing.

Keywords for Handling

  • try: Tests a block of code for errors.
  • except: Handles the error if an exception occurs.
  • else: Runs only if NO exception occurred.
  • finally: Runs ALWAYS, regardless of outcome.

Control Flow

  1. Python executes statements inside try block.
  2. If no error occurs, the except block is skipped.
  3. If an error occurs, execution jumps immediately to the except block!
Lesson 4.5.5 · Worked Example

Textbook Example: Safe Division

Comparing unhandled crash vs defensive try...except handling:

Without Exception Handling

x = 25
y = 0
result = x / y
print("Result is", result)

# Crash Traceback:
# ZeroDivisionError: division by zero

Program crashes immediately; lines below never execute!

With try...except (Page 221)

x = 25
y = 0
try:
    result = x / y
    print("Result is", result)
except:
    print("Not possible to divide")

# Output:
# Not possible to divide

Program handles error cleanly and continues running!

Lesson 4.5.6 · Aliasing Errors

Catching Error Objects: except Exception as e

Instead of guessing what went wrong, Python allows us to capture the exact exception object raised by using an alias as e.

Syntax & Textbook Example (Page 222)

x = 25
y = 0
try:
    result = x / y
    print("Result is", result)
except Exception as e:
    print("Cannot be divided", e)

# Output:
# Cannot be divided division by zero

Why Aliasing is Useful

  • e stores the exact message generated by Python.
  • Allows dynamic reporting without hardcoding error descriptions.
  • Crucial for debugging and writing error logs to files.
Lesson 4.5.7 · The else Clause

The else Block in Exception Handling

In Python, the else block in a try...except statement executes only if the try statement does NOT raise an exception.

Textbook Example (Page 222)

num1 = 25
num2 = 12
try:
    result = num1 / num2
except Exception as e:
    print("Cannot be divided", e)
else:
    print("Result is", result)

# Output:
# Result is 2.0833333333333335

Best Practice Rule

Keep the try block as small as possible (only the risky operation). Put the code that depends on the successful calculation inside the else block!

This prevents accidental catching of unexpected errors in non-risky code.

Lesson 4.5.8 · Guaranteed Execution

The finally Clause

The finally block always executes, no matter if the try block raises an error or executes smoothly.

Textbook Example (Page 223)

num1 = 25
num2 = 0
try:
    result = num1 / num2
    print("Result is", result)
except Exception as e:
    print("Cannot be divided", e)
finally:
    print("The program is finished.")

# Output:
# Cannot be divided division by zero
# The program is finished.

Real-World Cleanup Use Cases

  • Closing opened files (file.close())
  • Closing network sockets and database connections
  • Releasing hardware locks and temporary resources

Cleanup code in finally runs even if an error is unhandled or code returns early!

Lesson 4.5.8 · Master Blueprint

The Complete 4-Clause Blueprint

1. try

Enclose risky code that could trigger an exception.

2. except

Executes ONLY if an exception occurs in try.

3. else

Executes ONLY if NO exception occurs in try.

4. finally

Executes ALWAYS, without exception.

Execution order: try → (except OR else) → finally

Lesson 4.5.9 · Worked Examples

Program 1: Area & Volume of a Sphere

Official CDC Textbook Worked Example 1 (Pages 223–224):

Mathematical Formulas

  • Surface Area of Sphere: A = 4 π r²
  • Volume of Sphere: V = 4/3 π r³
  • Constant: π ≈ 3.14159... from math.pi

Python Implementation

import math as m

radius = float(input("enter the radius:"))
pie = m.pi

a = 4 * pie * pow(radius, 2)
v = 4/3 * pie * pow(radius, 3)

print("Area of the of the sphere is", a)
print("Volume of the of the sphere is", v)

Lesson 4.5.10 · Examination Guide

Short Answer Solutions for SEE Exam

Key Concept Answers

  • Role of except block: Executes when an error occurs in the try block to handle it gracefully and prevent a crash.
  • When else block executes: Only when the try block completes successfully without raising any exceptions.
  • Three error types: Syntax errors, Semantic (logical) errors, and Runtime errors.

Four Exception Handling Keywords

Be prepared to list and explain all four keywords in SEE theory:

  • try — encloses test code
  • except — handles raised exceptions
  • else — runs if no exception occurred
  • finally — guaranteed cleanup execution
