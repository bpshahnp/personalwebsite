Lesson 4.6.1 · Data Files

Concept of Data Files

Computers store large volumes of data and information in storage devices. Data is stored using the concept of a file.

What is a File?

A file is simply a collection of related information stored in a storage device. Every file is identified by its unique file name.

Examples: staff.txt, students.csv, report.pdf

Three Steps for Working with Files

  1. Open the file (create it if it doesn't exist).
  2. Read or Write information in the file.
  3. Close the file when all work is done.

The same procedure applies when writing Python programs for file operations.

Lesson 4.6.1 · Why File Handling

4.6.1 Concept of File Handling in Python

Why We Need File Handling

File handling is an essential concept in any programming language as it allows programs to store data permanently.

Without file handling, any data created during program execution would be lost when the program ends.

Python Built-in File Functions

  • open() — to open a file
  • read() / readline() — to read data from a file
  • write() — to write data to a file
  • append() — to add data to an existing file
  • close() — to close the file
Lesson 4.6.2 · Opening Files

4.6.2 Opening a File in Python

The first step when working with a file is to open it using the open() function.

Syntax

with open('Filename', 'mode') as file:
    # work with file here
    
# OR (older style):
file = open("File name", mode)

file is the variable (alias) that lets you access the opened file object inside the block.

Quick Examples

# Example 1: Create/overwrite employee.txt
f = open("employee.txt", "w")

# Example 2: Using 'with' statement
with open("teachers.txt") as f:
    # auto-closes after block

The with statement automatically closes the file — even if an exception occurs!

Lesson 4.6.2 · File Modes

File Open Modes

Mode 'r' — Read

Opens file for reading. Sets pointer to first character. Raises IOError if file does not exist.

with open("staff.txt", "r") as file:
    content = file.read()

Mode 'w' — Write

Opens file for writing. Creates new file if it doesn't exist. Overwrites existing content.

with open("employee.txt", "w") as f:
    f.write("Hello")

Mode 'a' — Append

Opens file in append mode. Adds data to the end of existing file. Creates new file if needed.

with open("log.txt", "a") as f:
    f.write("New entry
")

Mode 'x' — Exclusive Create

Creates a new file. Fails (IOError) if file already exists. Safe for new file creation.

with open("newfile.txt", "x") as f:
    f.write("Safe create")
Lesson 4.6.3 · Writing Files

Writing Information to a File

write() Function

Write function writes information (string) to the file. Use modes x or w to create/overwrite.

Syntax: file.write(information)

  • x: Creates new empty file; raises error if exists.
  • w: Creates new file or replaces existing one.

Textbook Example

with open('staff.txt', 'w') as f:
    f.write('Ramesh
')
    f.write('Kamal
')
    f.write('Kabin
')

Output in staff.txt (Notepad):

Ramesh
Kamal
Kabin

= newline escape character — starts writing on the next line.

Lesson 4.6.4 · Reading Files

Reading Information from Files

Python provides three functions to read data stored in a file.

read()

Reads and returns the ENTIRE content of the file as one string.

Syntax: file.read()

with open("staff.txt", "r") as file:
    content = file.read()
    print(content)
# Output: Ramesh
# Kamal
# Kabin

readline()

Reads and returns ONE LINE at a time from the current file pointer position.

Syntax: file.readline()

with open("staff.txt", "r") as file:
    content = file.readline()
    print(content)
# Output: Ramesh

readlines()

Reads ALL lines and returns a list where each element is one line.

Syntax: file.readlines()

with open("staff.txt", "r") as file:
    content = file.readlines()
    print(content)
# Output: ['Ramesh
',
#          'Kamal
',
#          'Kabin
']

Lesson 4.6.5 · Closing Files

Closing a File: close()

Why Close a File?

After completing all file operations, the file must be closed using file.close(). This:

  • Terminates all resources used by the file.
  • Frees system memory and I/O buffers.
  • Flushes any unwritten data to disk.

Syntax: file.close

Manual Close Example

file = open("stafftxt", "r")
content = file.read()
print(content)
file.close()  # Must close!

Better: Use 'with' Statement

with open("staff.txt", "r") as file:
    content = file.read()
    print(content)
# File auto-closed here!

The with statement automatically calls close() at the end.

Lesson 4.6.6 · CSV Files

4.6.3 Read and Write CSV File Using Standard Library

What is a CSV File?

CSV (Comma Separated Values) separates information using commas. Spreadsheet applications convert comma-separated data into table cells.

Structure example:

Name, Address, Class
Bipin, Kathmandu, 10
Shyam, Pokhara, 9
Sita, Bhaktapur, 10

CSV files have .csv extension and are human-readable.

csv Module Functions

  • csv.writer(file) — returns a writer object
  • cs.writerow(fields) — writes one row (e.g. headers)
  • cs.writerows(records) — writes multiple data rows
  • csv.reader(file) — returns a reader iterable

First, import csv to access the module.

Lesson 4.6.6 · Writing CSV

Textbook Example 1: Write Data to CSV File

Program (Page 233)

import csv
f = ['Name', 'Class', 'Address']
r = [
    ['Kamal', '10', 'Surkhet'],
    ['Binita', '9', 'Butwal'],
    ['Pawan', '10', 'Kathmandu']
]
with open("employees.csv", 'w', newline='') as file:
    cs = csv.writer(file)
    cs.writerow(f)    # Write header
    cs.writerows(r)   # Write all data rows

Output (in Excel)

Name   | Class | Address
Kamal  | 10    | Surkhet
Binita | 9     | Butwal
Pawan  | 10    | Kathmandu

writerow(f) writes the header list as one row.
writerows(r) writes the list of lists (each inner list = one data row).

Lesson 4.6.6 · Reading CSV

Textbook Example 2: Read Records from CSV File

Program (Page 233–234)

import csv
with open('employees.csv', mode='r') as file:
    cs = csv.reader(file)
    for i in cs:
        print(i)

Output

['Name', 'Class', 'Address']
['Kamal', '10', 'Surkhet']
['Binita', '9', 'Butwal']
['Pawan', '10', 'Kathmandu']

Filtering Specific Rows (Example 4)

import csv
with open("result.csv", "r") as file:
    r = csv.reader(file)
    for i in r:
        if i[1] == "10":
            print(i)

i[1] accesses the second field (Class column) of each row. This filters and prints only Class 10 students.

Lesson 4.6.7 · Pandas & CSV

Using Pandas Library for CSV Files

Writing CSV with Pandas: to_csv()

Pandas provides to_csv() to write a DataFrame to a CSV file.

import pandas as p
emp_name = ["Harish", "Yubaraj", "Pashupati"]
post = ["Manager","Officer","Programmer"]
salary = [55000, 65000, 90000]
dict = {'Name': emp_name,
        'Post': post,
        'Salary': salary}
df = p.DataFrame(dict)
df.to_csv('employee.csv')

Output includes auto-generated row index: 0, 1, 2.

Saving Without Index

df.to_csv('employee.csv', index=False)

Removes the numeric row index (0, 1, 2) from the CSV output.

Saving Without Index and Header

df.to_csv('employee.csv',
           index=False,
           header=False)

Both index=False AND header=False produce a clean data-only CSV with no row numbers or column names.

Lesson 4.6.7 · Pandas read_csv

Reading CSV with Pandas: read_csv()

Basic read_csv()

import pandas as p
data = p.read_csv('employees.csv')
print(data)
# Output:
#   Name  Class  Address
# 0 Kamal  10  Surkhet
# 1 Binita  9  Butwal
# 2 Pawan  10  Kathmandu

Advanced Parameters

# Select specific columns only:
data = p.read_csv("employees.csv",
        usecols=["Name", "Class"])

# Set index column:
data = p.read_csv("employees.csv",
        index_col=["Name"])

# Read only first N rows:
data = p.read_csv("employees.csv",
        nrows=2)
Lesson 4.6.7 · Pandas Filtering

Filtering Data after read_csv()

Filter Rows by Column Value

import pandas as p
data = p.read_csv("Emp.csv")
# Filter rows where Age > 25
n = data[data['Age'] > 25]
print(n)
import pandas as p
data = pd.read_csv("Employee.csv")
# Filter where Post is MANAGER
d = data[data['Post'].str.upper()
         == "MANAGER"]
print(d)

Multiple Conditions Filter

import pandas as p
data = pd.read_csv("Student.csv")
# Class == 10 AND Age > 15
d = data[(data['Class'] == 10)
         & (data['Age'] > 15)]
print(d)

Use & for AND, | for OR in Pandas boolean filters. Each condition must be in parentheses!

Lesson 4.6.8 · Worked Examples

File Handling Using CSV Module: Worked Examples

WE1: Write Name/Age/Address of 4 staffs to staff.csv

import csv
with open("staff.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Name", "Age", "Address"])
    for i in range(1, 5):
        name = input("Enter the Name:")
        age = input("Enter the age:")
        address = input("Enter the address:")
        writer.writerow([name, age, address])

WE3: Display records where age is 50

import csv
with open("staff.csv", "r") as file:
    data = csv.reader(file)
    for i in data:
        if i[1] == "50":
            print(i)

i[1] = second field = Age column (index 1). Note: CSV reader returns all values as strings, so compare with "50" not 50.
