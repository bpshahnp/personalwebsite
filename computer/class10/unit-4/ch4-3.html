4.3 · Lesson 1: Concept of Library

Concept of Library in Python

Textbook DefinitionA Python library is a collection of pre-written modules and packages that provide reusable functionality for specific tasks, making coding faster and easier.

1. Python Standard Library

Built-in collection of modules distributed with Python. Ready to use immediately without separate installation.

Examples: math, random, os, sys, turtle

2. External Libraries

Collections of modules created by the community. Must be installed separately using the pip package manager.

Examples: matplotlib, pandas, numpy, scipy, scikit-learn

4.3 · Lesson 2: Popular Libraries

Popular External Python Libraries

Matplotlib

Data visualization. Used for plotting numerical data into figures like pie charts, histograms, scatter plots, and line graphs.

Pandas

Data science & analysis. Handles tabular data (rows and columns) like spreadsheets and CSVs, offering data cleaning and statistics.

NumPy

Numerical Python. Foundation for machine learning; provides support for large multi-dimensional arrays and matrices.

SciPy & Scikit-learn

SciPy handles high-level scientific computations. Scikit-learn provides machine learning algorithms for predictive modeling.

4.3 · Lesson 3: Python Packages

Python Packages

Textbook DefinitionA Python package is a collection of related Python modules that are organized into a folder/directory. A package can simply be created by organizing modules into a folder and adding a special file called __init__.py.

  • Packages help structure large programs into modular, hierarchical directories.
  • Allows reusable distribution of code across software teams.
  • Built-in package examples: collections, datetime, email, sqlite3.

Directory Structure of a Package

my_package/
    __init__.py
    module1.py
    module2.py
    subpackage/
        __init__.py
        helper.py
4.3 · Lesson 4: Import Syntax

Four Ways to Import in Python

1. Import Entire Module

import math
print(math.sqrt(49)) # 7.0

Requires prefixing with module.

2. Specific Items

from math import sqrt
print(sqrt(100)) # 10.0

No module prefix needed.

3. Renaming (Alias)

import math as m
print(m.sqrt(169)) # 13.0

Renames long module names.

4. Wildcard Import (*)

from math import *
print(factorial(5)) # 120

Imports all public functions.

4.3 · Lesson 7: Pandas

The Pandas Library

External LibraryInstalled via pip install pandas. Primarily used for tabular data analysis, data cleaning, and dataset statistics.

Pandas Series (1D)

One-dimensional array with labeled indices:

import pandas as pd
data = ['Kamal', 'Programmer', 45]
ser = pd.Series(data, index=['Name', 'Post', 'Age'])
print(ser)

Pandas DataFrame (2D)

Two-dimensional table with labeled rows and columns:

data = {
    'Name': ['Kamal', 'Sita', 'Ram'],
    'Age': [25, 28, 22],
    'City': ['Kathmandu', 'Pokhara', 'Lalitpur']
}
df = pd.DataFrame(data)
print(df)
4.3 · Lesson 8: Matplotlib

The Matplotlib Library

External LibraryInstalled via pip install matplotlib. Conceived by John D. Hunter in 2003 for publication-quality charts and static/interactive visualizations.

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

plt.plot(x, y)
plt.title("Line Plot Example")
plt.xlabel("X-axis")
plt.ylabel("Y-axis")
plt.grid(True)
plt.show()

Core Plotting Routines

  • plt.plot(x, y): generates line plot.
  • plt.title('...'): sets graph title.
  • plt.xlabel() / plt.ylabel(): labels axes.
  • plt.grid(True): adds reference grid.
  • plt.show(): renders plot window.
4.3 · Lesson 9: Worked-out Programs

Worked-Out Library Programs

1. Area & Volume of Sphere

import math as m
r = float(input("Enter radius: "))
area = 4 * m.pi * m.pow(r, 2)
volume = (4/3) * m.pi * m.pow(r, 3)
print(f"Surface Area: {area:.2f}")
print(f"Volume: {volume:.2f}")

2. Factorial of a Number

from math import factorial
n = int(input("Enter number: "))
f = factorial(n)
print("Factorial is:", f)

3. Random Range

import random
r = random.randint(1, 100)
print("Generated:", r)
