Lesson 4.7.1 · Core Concepts

4.7 Concept of Data Visualization

Data visualization is the process of converting raw data into organized pictorial formats such as charts, graphs, and maps.

Why Raw Numbers Aren't Enough

Reading thousands of rows in spreadsheets or databases is slow, tiring, and error-prone. The human brain processes visual imagery 60,000× faster than text!

Visualization makes complex information intuitive, clear, and actionable.

Core Objectives

  • Identify hidden patterns and anomalies in large datasets
  • Observe changes, trends, and growth over time
  • Present compelling data stories to audiences and stakeholders
  • Empower fast, accurate, data-driven decisions
Lesson 4.7.1 · Business Value

Importance of Data Visualization

1. Instant Trends

Identify positive/negative patterns at a single glance without manual computation.

2. Quick Insights

Extract meaningful correlations between different factors (e.g. study hours vs marks).

3. Faster Decisions

Managers and educators make evidence-backed decisions in minutes.

4. Engagement

Visual charts hold audience interest far better than raw tables of numbers.

CDC Textbook: "Data visualization plays a vital role in sectors like business, education, healthcare, and research."

Lesson 4.7.2 · Ecosystem

Different Libraries for Visualization

Python supports multiple powerful libraries for data visualization, each with distinct strengths:

1. Matplotlib

The foundational plotting library. Creates static, publication-quality 2D charts (bar, scatter, line, histogram).

Command: pip install matplotlib

2. Seaborn

Built directly on top of Matplotlib. Specialized for attractive statistical graphics with built-in color themes.

Command: pip install seaborn

3. Plotly

Modern interactive visualization library. Generates interactive web charts with hover tooltips, zoom, and Dash support.

Command: pip install plotly

Lesson 4.7.3 · Matplotlib

Matplotlib: Bar Chart (Page 244–245)

A bar chart uses rectangular bars where each bar's length or height represents the value/frequency of a category.

Code Example

import matplotlib.pyplot as plt

fruits = ['Apple', 'Banana', 'Mango', 'Orange']
quantity = [25, 30, 15, 20]

plt.bar(fruits, quantity, color='skyblue')
plt.title('Fruit Quantity')
plt.xlabel('Fruits')
plt.ylabel('Quantity')
plt.show()

Key Functions Explained

  • plt.bar(x, y, color=...): Draws the rectangular bars.
  • plt.title('...'): Sets the chart headline.
  • plt.xlabel('...') & plt.ylabel('...'): Labels the axes.
  • plt.show(): Opens the GUI window displaying the plot!
Lesson 4.7.3 · Scatter Plots

Matplotlib: Scatter Plot (Page 245–246)

A scatter plot shows the relationship between two numerical variables using individual dots plotted on a Cartesian plane.

Height vs Weight Example

import matplotlib.pyplot as plt

height = [150, 155, 160, 165, 170, 175]
weight = [45, 48, 52, 56, 60, 65]

plt.scatter(height, weight)
plt.title('Height vs Weight')
plt.xlabel('Height (cm)')
plt.ylabel('Weight (kg)')
plt.show()

Visual Interpretation

As height increases along the X-axis (from 150 to 175 cm), weight also rises steadily along the Y-axis (from 45 to 65 kg).

This displays a strong positive correlation between human height and weight!

Lesson 4.7.4 · Seaborn

Seaborn: Statistical Visualizations

Seaborn is built on top of Matplotlib and integrates directly with Pandas DataFrames to produce elegant statistical graphs.

Monthly Sales Trend (Page 246–247)

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

data = {
  'Month': ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
  'Sales': [200, 250, 300, 280, 350]
}
df = pd.DataFrame(data)

sns.lineplot(x='Month', y='Sales', data=df, marker='o')
plt.title("Monthly Sales Trend")
plt.xlabel("Month")
plt.ylabel("Sales")
plt.show()

Why Combine Seaborn + Matplotlib?

  • sns.lineplot() renders the smooth line and data points.
  • marker='o' highlights actual monthly values with circular dots.
  • Matplotlib's plt.title and plt.show() are used to finalize and display the canvas.
Lesson 4.7.5 · Plotly

Plotly: Interactive Web Visualizations

Plotly creates rich, dynamic visualizations where users can hover to inspect data coordinates, zoom in, pan, and toggle series.

Scatter Plot with Plotly Express

import pandas as pd
import plotly.express as px

dataset = pd.read_csv("employee.csv")
graph = px.scatter(dataset, x="Name", y="Salary")
graph.show()

Opens an interactive graph in your web browser!

Line Graph with Plotly Express

import pandas as pda
import plotly.express as px

dataset = pda.read_csv("employee.csv")
graph = px.line(dataset, x="Name", y="Salary")
graph.show()

Renders an interactive line connecting each employee to their salary.

Project File Header Initialization

import csv
filename = "student_results.csv"

# Create file with headers if not exists
try:
    with open(filename, "x", newline="") as file:
        writer = csv.writer(file)
        writer.writerow(["Roll", "Name", "Project Marks",
                         "Viva Marks", "Report Marks",
                         "Total", "Percentage", "Grade"])

    pass  # File already exists, continue

Mode "x" creates the file safely; if it exists, exception is caught gracefully!

def search_student():
    roll = input("Enter Roll Number to Search: ")
    found = False
    with open(filename, "r") as file:
        reader = csv.reader(file)
        for row in reader:
            if row and row[0] == roll:
                print(f"Name: {row[1]}")
                print(f"Total: {row[5]}")
                print(f"Percentage: {row[6]}")
                print(f"Grade: {row[7]}")
                found = True
                break
    if not found:
        print("No student found with that roll number.")
