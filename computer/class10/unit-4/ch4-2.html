4.2 · Lesson 1: Concept & Advantages

What is a Function?

Textbook DefinitionA function is a block of code that performs a specific task. It is a reusable block of code that makes a program easier to understand, test, debug, and modify.

  • Functions modularize programs by breaking large, complex problems into smaller, manageable subprograms.
  • Also referred to as procedures or subroutines in other programming languages.
  • Can be called multiple times from different parts of a program, providing code reusability.

Library Functions

Predefined functions supplied in Python libraries (e.g., sqrt(), min(), max(), len()). Ready to use, often requiring a module import.

User-defined Functions

Functions written by the programmer to meet specific task requirements. Custom names, parameters, algorithms, and return behaviors.

4.2 · Lesson 1: Concept & Advantages

Advantages of Functions

Modularizing software into functions offers fundamental software engineering benefits:

Code Reusability

Write once, use anywhere. Eliminates the need to rewrite the same algorithm repeatedly across the program.

Reduces Code Size

Replaces duplicate sets of statements with concise function calls, significantly reducing code redundancy.

Easier Debugging

Isolates logic into self-contained units so bugs and errors can be traced and corrected rapidly.

Team Development

Large projects can be split into smaller modules developed concurrently by separate programmers.

4.2 · Lesson 2: Creating Functions

Creating User Defined Functions

Syntax RuleA function definition begins with the def keyword, followed by the function name, parentheses containing optional parameters, and a colon :.

def <function_name>([param1, param2, ...]):
    # statements (algorithm)
    statements
    [return <value>]

# Function call:
function_name(arg1, arg2, ...)
  • def: Keyword telling Python you are defining a function.
  • Parameters inside [ ] are optional.
  • Colon (:): Required at the end of the header.
  • Indentation: All statements inside the function must be indented.

Naming Rules

Function names follow the exact same rules as Python variables:

  • Must start with a letter or underscore (_).
  • Cannot start with a digit (e.g. 2add is invalid).
  • Only alphanumeric characters & underscores.
  • Case-sensitive (sum() ≠ Sum()).
  • Cannot use Python reserved keywords (like for, if, while).
4.2 · Lesson 3: Function Calls

Function Call & Program Flow

ConceptA function call is the invocation of a function when required. When called, program control transfers to the function body, executes its statements, and then returns control back.

Code Example

    z = x + y
    return z

# Calling the function:

4.2 · Lesson 4: Parameters vs Arguments

Parameters vs Arguments

Although often used interchangeably in casual talk, they have distinct technical meanings:

Parameters (Formal Parameters)

Definition HeaderVariables declared inside the function definition header.

  • Act as placeholders for data that will be passed in.
  • Define the number and type of inputs expected.
  • Example: In def add(x, y):, x and y are parameters.

Arguments (Actual Parameters)

Function CallThe actual values or expressions supplied during a function call.

  • Fill the parameters with real data during execution.
  • Can be constants, variables, or expressions.
  • Example: In s = add(70, 50), 70 and 50 are arguments.
4.2 · Lesson 5: Variable Scope

Scope of Variables (Local vs Global)

DefinitionScope refers to the visibility and lifetime of a variable—which parts of your program can see and access it.

Local Variable

Declared inside a function. Can only be accessed within that function.

  • Created when the function is called.
  • Destroyed when function execution ends.
  • Cannot be accessed from outside the function.

Global Variable

Declared outside of all functions in the main body.

  • Has a broader scope.
  • Accessible across multiple functions and modules.
  • Persists as long as the program runs.

4.2 · Lesson 6: Return Values

Returning Values from Functions

Functions in Python can be classified into three categories based on return behavior:

1. Functions Returning Value

Non-void functions. Use return <value> to send data back to caller.

def product(a, b, c):
    p = a * b * c
    return p
mul = product(10, 20, 30)
# mul receives 6000

2. Void Functions (No Return)

Perform an action (like printing) and do not return data. Implicitly return None.

def product(a, b, c):
    p = a * b * c
    print("Product:", p)
# Returns None

3. Multiple Return Values

Python can return multiple values separated by commas, packed automatically as a tuple.

def square(a, b):
    return a*a, b*b
s1, s2 = square(5, 6)
# s1=25, s2=36

Returning Multiple Values & Unpacking

Tuple Packing & Unpacking

def square(a, b, c):
    return a*a, b*b, c*c

# 1. Unpacking into separate variables:
s1, s2, s3 = square(10, 20, 30)
print(s1, s2, s3)

4.2 · Lesson 7: Types of Arguments

Types of Function Arguments

Python provides four distinct mechanisms for passing arguments to functions:

1. Positional Arguments

Values must match the exact position and sequence of parameters in the definition.

def sum(x, y, z):
    return x + y + z
sum(80, 32, 100) # 212

2. Default Arguments

Parameters assigned fallback values with =. Caller can omit them.

def sum(x=50, y=100):
    return x + y
sum() # 150

3. Keyword Arguments

Arguments passed by parameter name (name=val). Order does not matter.

def data(name, age): ...
data(age=20, name="Ramesh")

4. Arbitrary (*args)

Asterisk * collects variable number of arguments into a tuple.

def addition(*nums):
    return sum(nums)
addition(1, 2, 3, 4)
4.2 · Lesson 7: Types of Arguments

Default vs Arbitrary Arguments

Default Arguments

def calc(x=50, y=100):
    return x + y

print(calc(1000, 2000)) # 3000 (both override)
print(calc(500))         # 600 (x overrides, y default)
print(calc())            # 150 (both default)

Arbitrary Arguments (*num)

def addition(*num):
    s = 0
    for value in num:
        s += value
    print("Sum is:", s)

addition(100, 20)
addition(100, 200, 300, 400, 500)
4.2 · Lesson 8: Worked-out Programs

Classic Function Programs

1. Factorial of a Number

def fact(num):
    if num < 0:
        return "Not for negative"
    f = 1
    for i in range(1, num + 1):
        f *= i
    return f

print(fact(5)) # 120

2. Reverse a Number

def reverse(num):
    rev = 0
    while num > 0:
        digit = num % 10
        rev = rev * 10 + digit
        num //= 10
    return rev

print(reverse(783)) # 387

3. Vowels Count

def vowels(w):
    w = w.upper()
    c = 0
    for ch in w:
        if ch in "AEIOU":
            c += 1
    return c

print(vowels("Computer")) # 3

Math & Conversion Functions

Circle Area & Perimeter

def area(r):
    return (22 / 7) * r * r

def perimeter(r):
    return 2 * (22 / 7) * r

r = float(input("Enter radius: "))
print(f"Area: {area(r):.2f}")
print(f"Perimeter: {perimeter(r):.2f}")

Temperature Conversion

def to_fahrenheit(c):
    return (c * 9 / 5) + 32

def to_kelvin(c):
    return c + 273.15

c = float(input("Enter Celsius: "))
print("Fahrenheit:", to_fahrenheit(c))
print("Kelvin:", to_kelvin(c))

CDC Textbook Questions Summary

Essential takeaways for Class 10 Board Examinations:

Key Concepts

  • def keyword begins function definition.
  • Header ends with colon : and body is indented.
  • return sends value back; omitting it returns None.

Terminology Checklist

  • Parameters: Formal placeholders in def.
  • Arguments: Real values supplied in call.
  • Local variable: Function scope, temporary.
  • Global variable: Module scope, persistent.

Argument Modes

  • Positional: order matters.
  • Default: x=50 fallback.
  • Keyword: name='Ram' order-independent.
  • Arbitrary: *args receives tuple.
